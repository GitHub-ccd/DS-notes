# Section 00 — Descriptive Statistics

Foundational statistics: reading mathematical notation, summarizing data with central tendency and dispersion measures, and understanding relationships between variables with covariance and correlation. This section is the prerequisite gate before probability theory begins in Section 01.

## Notebooks

| Notebook | Topic |
|----------|-------|
| `01_mathematical_notation.ipynb` | Sigma and Pi notation, Greek letters reference — reading formulas without panic |
| `02_central_tendency.ipynb` | Mean, median, mode — when to use each, effect of outliers and distribution shape |
| `03_dispersion.ipynb` | Variance, standard deviation, IQR, percentiles, box plots |
| `04_correlation_and_covariance.ipynb` | Covariance and Pearson correlation — lesson + lab built from scratch in Python |
| `05_implementing_statistics.ipynb` | Capstone: implement all measures from scratch on the NHIS dataset |
