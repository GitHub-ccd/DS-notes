# Section 03 — NumPy, Pandas & Visualization

The core data science computing stack: arrays, DataFrames, and the full visualization pipeline from quick EDA plots to publication-ready figures. Merges and consolidates the previous `04_pandas_visualization/` and `06_Seaborn_viz/` sections.

## Notebooks

| Notebook | Topic |
|----------|-------|
| `01_python_libraries_intro.ipynb` | Stack overview (NumPy/Pandas/Matplotlib/Seaborn), import conventions, API exploration |
| `02_numpy.ipynb` | Arrays, dtypes, vectorized math, broadcasting, indexing, aggregations |
| `03_pandas_data_structures.ipynb` | Series, DataFrames, creation patterns, index alignment, inspection |
| `04_pandas_data_access.ipynb` | `.loc[]`, `.iloc[]`, boolean indexing, `.query()`, modifying subsets |
| `05_importing_data.ipynb` | `read_csv`, JSON, Excel, SQL; key parameters, post-load checklist |
| `06_statistical_analysis_with_pandas.ipynb` | `.describe()`, `.groupby()`, `.agg()`, correlation, `.apply()`, `.transform()` |
| `07_data_ethics.ipynb` | Bias taxonomy, protected attributes, fairness metrics, real-world case studies |
| `08_visualization_with_pandas.ipynb` | `.plot()` API: line, bar, hist, scatter, box charts from DataFrames |
| `09_visualization_best_practices.ipynb` | Encoding hierarchy, misleading charts, pre-attentive attributes, accessibility |
| `10_matplotlib.ipynb` | Figure/Axes architecture, multi-panel layouts, custom annotations, styles |
| `11_seaborn.ipynb` | Relational, distributional, categorical plots; pair plots, heatmaps, facet grids |
| `12_eda_project.ipynb` | Capstone: full EDA on King County house sales using the OSEMN framework |
