## 2026 Context

REST APIs are a foundational skill but LLM APIs have become the most common new API integration for data scientists. Key patterns: HTTP requests via `requests`, JSON parsing, API key authentication. LLM-specific additions: structured output (JSON mode), streaming responses, tool use (function calling), and prompt caching. `08_llm_apis.ipynb` covers the Anthropic and OpenAI patterns in depth.
