## 2026 Context

GitHub now defaults to `main` as the default branch name for new repositories (changed from `master` in 2020). Git 2.23 introduced `git switch` as a cleaner alternative to `git checkout` for changing branches — both still work. To rename an existing local branch: `git branch -M main`.
